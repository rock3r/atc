# ATC 3.3.0

- **Isolated Bazel query profile:** `bazel.query` and `bazel.cquery` accept typed isolation fields. Startup options (`noSystemRc`, `noHomeRc`, `bazelrc`, private `outputUserRoot`/`outputBase`, `serverJavabase`, `hostJvmArgs`) are placed before the verb. Command options (`repositoryCache`, `diskCache`, `repoEnv`, empty `remoteCache`/`remoteExecutor`/`besBackend`, `lockfileMode`, and cquery-only `noWorkspaceSymlinks`) are placed after it. ATC does not parse a shell. Private paths must be absolute, must not contain a caller-chosen symlink, and must not resolve into the workspace or the OS account's `~/Library/Caches/JetBrains` or `~/Library/Caches/bazel`. The account home is `os.userInfo().homedir`, not a process or batch `HOME`. These fields are not an OS write sandbox and do not stop repository-rule writes into the workspace. `3.2.0` has no isolation fields and must not be used on a protected original. (#28)
