# ATC 3.5.0

- **Snapshot budget:** `atc snapshot save|list|load|delete` records managed snapshots in a machine-wide registry. A label that already exists exits 4 and changes nothing unless `--replace` is passed. A known budget miss exits 5 and creates nothing. A successful save that then measures over budget exits 0 and says to ask the user what to do.
- **Defaults:** the budget is 16384 MB, the TTL is 7 days, and at most 8 snapshots can be pinned. TTL does not promise retention when the byte budget is full. A retained pin counts against that pin limit, and an explicit delete can remove a replaced snapshot that was kept.
- **Claims:** claim and free resolve a managed label to its backend id. A stale id cannot load newer bytes. A managed label cannot be saved through `atc free --snapshot-save`.
