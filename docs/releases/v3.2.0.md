# ATC 3.2.0

- **Typed Bazel graph inspection:** `bazel.query` and `bazel.cquery` run through `atc exec`, MCP, and `atc batch` under the workspace lock and build slot. The query expression is one literal argument. Output is an allowlisted format written to a relative `outputFile`, published only when Bazel exits 0 inside `maxOutputBytes`, with byte count and SHA-256. A limit breach, failure, cancellation, or interrupted write leaves no artifact. Compare those hashes to certify a `//:main` closure; a successful build or a stored digest does not. (#26, #27)

**Full changelog:** https://github.com/rock3r/atc/compare/v3.1.0...v3.2.0
