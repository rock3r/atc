# ATC 3.4.0

- **iOS simulator create:** `atc claim --ios --create-if-missing` passes the device type and runtime from `simctl list` into `xcrun simctl create`. It no longer stringifies a missing field as `undefined`. `createIosSimulator` refuses an empty device type instead of calling `simctl`.
- **iOS simulator delete:** `atc exec ios delete <udid>` shuts down and deletes the simulator this session currently leases, then drops the lease and advances the fleet epoch so a concurrent claim cannot reuse a stale inventory. It refuses a different UDID and a physical lease. (#30)

**Full changelog:** https://github.com/rock3r/atc/compare/v3.3.0...v3.4.0
